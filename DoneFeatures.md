# pypstreader — DoneFeatures

Every row that has landed, in the order it landed, with the verification that
closed it. This is the project's build record: `MasterToDo.md` carries only
what is still open, and a row moves here the day it is done.

A row is done only with evidence recorded on it — a test count, an oracle
diff, a sha. "It runs" was never the bar; agreeing with the Rust oracle byte
for byte on every fixture was.

## 1.0.0 — the read path, complete

B-trees, blocks), LTP (heap, BTH, property and table contexts), and messaging
(store, named properties, folders, messages, recipients, attachments, embedded
messages), plus export to `.eml` and mbox and the command on top of it.
